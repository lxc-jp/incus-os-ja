# 非プライマリーアプリケーション

IncusOSはプライマリーアプリケーションの機能を強化したりデバッグのサポートを提供するために非プライマリーアプリケーションを使用します。

```{tip}
以下を実行することでIncusOSに非プライマリーアプリケーションをインストールできます。

    incus admin os application add -d '{"name":"<application name>"}'
```
